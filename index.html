tdcpy Documentation#

tdcpy: Control of time-delay systems in Python

tdcpy is a package for analysis and control of time-delay systems. The software is based on the TDS-Control toolbox in MATLAB [Appeltans and Michiels, 2023]. Like TDS-Control, tdcpy provides tools for modeling, spectral analysis and controller design of time-delay systems.

  • Modelling time-delay systems

  • Performing spectral analysis

  • Designing stabilizing controllers

  • And more!
