Examples
========

Below are examples demonstrating the usage of `tdcpy` package.

Examples are divided thematically into groups and we recommend to start from top.
If you are coming from MATLAB package ``tds-control``, we recommend starting
with the :ref:`these <tds_control_manual_examples>` examples.

Attention deserves also :ref:`section with applications <applications_examples>`
that demonstrates real-world usecases for the package.

At the end, you find :ref:`tutorials <tutorials>` - more in-depth
examples that cover specific topics step by step.
