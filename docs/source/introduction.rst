TDSpy is a Python package for analysis and control of time-delay systems. The package includes tools for modeling, analysis and controller design for time-delay systems of retarded type, neutral type and delay descriptor systems. 
The current version of TDSpy offers the following core functionalities:

.. 1. **Modeling**
..     * time-delay systems of retarded type
..     * time-delay systems of neutral type
..     * delay descriptor systems (described by delay differential-algebraic equations (DDAEs))

1. **Stability analysis** 
    * computing the characteristic roots of retarded and neutral systems
    * computing the spectral abscissa and the strong spectral abscissa of a time-delay systems

2. **Stabilization** 
    * design of static controllers
    * design of dynamic controllers

3. **Visualization** 
    * spectral abscissa plots
    
A set of examples are provided to illustrate the functionality of TDSpy.
