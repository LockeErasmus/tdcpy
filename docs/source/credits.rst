Citing this work
----------------

If you publish work that makes a good use of this python package, please cite
the repository

.. code-block:: bibtex

   @misc{tdspy,
     author    = {Peichl, Adam and Saldanha, Adrian},
     title     = {TDSpy},
     year      = {2026},
     version   = {1.0.0},
     url       = {https://github.com/LockeErasmus/tdspy},
   }

Additionaly, we encourage you to cite the original article from which the
specific algorithm comes from. We always include reference in the docstrings.
